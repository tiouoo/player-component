# 桌面音乐播放器控制组件

基于 Tauri + Vue 3 开发的轻量级桌面音乐播放器控制组件，支持 Windows 系统媒体控制。

## 功能

- 实时显示当前播放的音乐信息
- 播放控制（播放/暂停、上一曲/下一曲）
- 系统音量静音控制
- 4 种显示模式切换（Ctrl+Q）
- 支持多个媒体会话切换

## 运行项目

### 环境要求

- Node.js 16+
- Rust 1.70+
- Windows 系统

### 源代码运行

```bash
git clone https://github.com/tiouoo/player-component.git
cd player-component
npm install
npm run tauri dev
```
